# قائمة تحقق المصادر المرشحة

هذه القائمة مبنية على `tools/content_sources.candidate.json`. لا تعني أن أي مصدر فيها معتمد أو أن الإذن مثبت.

## المستندات المطلوبة لكل مصدر

- صورة صفحة العنوان.
- صورة صفحة بيانات النشر.
- رقم الطبعة والسنة.
- اسم الجهة المالكة للحقوق.
- خطاب الإذن، إن كان النص محميًا.
- اسم المراجع الكنسي.
- تاريخ المراجعة.
- قرار اعتماد الإصدار الأول.

## قاعدة التحويل إلى مصدر رسمي

لا يتغير المعرّف إلى مصدر رسمي ولا ينتقل `review_status` إلى `approved` إلا بعد إرفاق المستندات وتسجيل:

```text
permission_reference
verified_by
verified_at
source_ref
```

الانتشار، التداول الكنسي، أو وجود PDF على الإنترنت لا يساوي إذن إعادة النشر داخل تطبيق.
