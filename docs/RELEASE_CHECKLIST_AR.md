# قائمة إصدار نور لنشر Android

## قبل تشغيل إصدار الإنتاج

- [ ] تمت مراجعة قائمة `review_sheets/CONTENT_REVIEW_QUEUE_AR.md` وتوقيعها.
- [ ] لا توجد قواعد طقسية مفعلة بلا مرجع واعتماد.
- [ ] تم تشغيل `flutter analyze` بنجاح.
- [ ] تم تشغيل `flutter test --coverage` وتسجيل النسبة.
- [ ] تم تشغيل اختبارات المحتوى Python.
- [ ] تم اختبار الترحيل على نسخة مستخدم قديمة.
- [ ] تم اختبار FTS5 على جهاز Android فعلي.
- [ ] تم اختبار حجم الخط الكبير وTalkBack ووضع AMOLED.
- [ ] تمت مراجعة سياسة الخصوصية وData Safety.
- [ ] تم التأكد من دعم صفحات الذاكرة 16KB في Flutter والمكتبات الأصلية.
- [ ] تم اختبار AAB على مسار مغلق قبل النشر العام.

## أسرار GitHub Environment: production

يجب تعريف الأسرار التالية في GitHub Environment محمي، ولا تُحفظ في Git:

- `KEYSTORE_BASE64`
- `KEY_ALIAS`
- `KEY_PASSWORD`
- `STORE_PASSWORD`

لا تُنشئ keystore جديدًا أثناء CI. ضياع keystore الأصلي يمنع تحديث التطبيق المنشور.

## بناء الإصدار

شغّل يدويًا Workflow:

```text
Android release bundle
```

وأدخل رقم الإصدار، ثم راجع artifact الناتج:

```text
app-release.aab
symbols/
```

احتفظ بملفات `symbols` في تخزين آمن مطابق لرقم الإصدار؛ لا ترفعها إلى المستودع.

## تحقق ما بعد البناء

- [ ] التوقيع ليس debug.
- [ ] `versionName` و`versionCode` صحيحان.
- [ ] التطبيق يعمل دون اتصال.
- [ ] الإشعارات معطلة افتراضيًا.
- [ ] لا توجد أذونات غير ضرورية.
- [ ] لا توجد بيانات تحليل أو أعطال ترسل دون موافقة.
- [ ] تم تثبيت AAB على جهاز اختبار فعلي.
